Projekt 1 · Smart City

LoRaWAN-Gateway-System

Sensoren in Lindau messen Umweltdaten und senden sie per Funk an ein Gateway auf dem Schulgelände. Von dort gelangen die Werte ins Internet, wo sie alle einsehen können.

Funktionsweise

Vom Sensor ins Web

Das System besteht aus vier Teilen. Jeder Messwert nimmt denselben Weg.

  1. Sensormisst und sendet den Wert per LoRaWAN
  2. Gatewayempfängt die Funksignale auf dem Schulgelände
  3. The Things Networkleitet die Daten ins Internet weiter
  4. Webserverspeichert die Werte und stellt sie dar

Gateway

Ein offenes Netz für die Region

Auf dem Schulgelände entsteht ein Gateway für The Things Network (TTN).

TTN ist ein gemeinschaftlich betriebenes Netz, über das LoRaWAN-Sensoren ihre Daten ins Internet übertragen. Unser Gateway ist ein öffentlicher Zugangspunkt: Auch andere Menschen, Schulen und Organisationen in der Region können ihre Sensoren darüber anbinden.

Je nach Projektverlauf sind weitere Gateway-Standorte denkbar.
